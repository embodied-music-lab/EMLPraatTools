# Ruling — retire every rule, run bare, rebuild from the residue

Fable with Ian, 27 August 2026. **Supersedes the eight-rule audit
instruction.** It replaces rule archaeology entirely.

## The instruction

**Retire the whole `DECLARED[]` list and run the kit bare at a named commit.
Every row compares. Nothing is excused.**

Then adjudicate ONLY what actually disagrees or has no counterpart — the
MEASURED RESIDUE, not the inherited explanations.

**Rebuild the rule set from that residue alone.** Each surviving entry:

- is one of the three lawful kinds — a documented absence, a
  definition-over-implementation divergence, or a named tolerance
- cites the ruling that justifies it
- covers rows that MEASURABLY need it

**Nothing else survives.** The old rules are input to nothing. Where one
happens to describe real residue, the new entry is WRITTEN FROM THE
MEASUREMENT, not carried over.

## The expected shape of the residue

Stated so nobody panics at the bare run's red:

- the 258 R-side `wilcoxest` rows
- the two-way ~1e-8 family
- the Dunn absences
- whatever `D-WILCOXR` turns out to be
- **and anything genuinely new, which is exactly what this exists to
  surface**

## Why this is complete

The balance invariant already enforces that every row lands in compared,
documented-absent or tolerance-bounded. **So the new set is complete by
arithmetic**, and the falsification-provenance law applies to each new entry
from birth.

## Why this is less work

Strictly less than auditing 22 rules, and it produces a rule set with a
measured reason for every line.
