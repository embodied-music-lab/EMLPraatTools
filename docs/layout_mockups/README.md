# Layout mockups — worked examples, not fixtures

The scripts and screenshots here are the rendered mockups Ian approved on
24 August 2026, attached to `docs/RULING_LAYOUT_GROUPS.md`. Each script was
rendered under Xvfb on Praat 6.6.30 and eyeballed before approval.

**They are illustrations of the target, not committed fixtures.** Nothing
reads them, nothing drives them, and no check asserts against them. The
pages' own code is the implementation; when a page and a mockup disagree, the
page is what shipped and the mockup is what was approved — which is a
conversation, not a defect.

They are kept because a picture of the intended page settles an argument that
a paragraph does not.
