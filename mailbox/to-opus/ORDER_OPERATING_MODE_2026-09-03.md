## 2. The mode, five rules

1. **Decisions come from me, pre-made.** Work orders arrive with
   the choices already ruled. You send OPTIONS only for something
   genuinely novel; the default memo is findings + evidence, not
   an option menu. When in doubt whether a decision is yours: it
   is not — flag and continue on the parts that are.
2. **Your memory is not evidence and not state.** Anything you
   act on must be re-read from disk in the same working session:
   the ruling file, the tracker, INDEX_RULINGS (new, see below),
   PROCEDURE.md, the current work order. "I recall that we
   decided" is not a citable source for ANY claim or action —
   compaction has already falsified it at least twice (three
   re-asked ruled questions on 2 Sep; the stale-copy landed
   claims).
3. **Compaction declaration duty.** When you compact (or cannot
   rule out having compacted — a gap you can't account for, a
   detail that surprises you in your own files), your NEXT memo
   says so in its header line, and before resuming you rebuild
   state from the named re-read set above — not from what you
   remember. A declared compaction costs nothing; an undeclared
   one costs a wave.
4. **Every claim ships with its evidence** — command + output, or
   commit + path + line. This was standing; it is now an
   acceptance condition: a memo asserting something bare gets the
   assertion treated as unverified, not as fact.
5. **I audit every wave at the bundle before acceptance**, the way
   this one was audited. Cut bundles so they verify: same-day
   bundles may be thin against the repository of record's main,
   and the claims your memo makes should be checkable inside what
   the bundle carries plus that base.
